# Dispatch System — conceito visual

Imagem gerada em 2026-10-26 a partir da captura anterior e da leitura do projeto `whatsappQR/front`. É uma proposta de interface para o portfólio, não uma captura da aplicação publicada. Os números e as campanhas são fictícios.

O visual reorganiza o fluxo real do produto: importar contatos por Excel, gerenciar banners/templates, enviar, consultar o status e cancelar envios. Usa uma navegação lateral compacta, resumos, atividade de envio, lista de campanhas e ações rápidas. A direção visual privilegia fundo claro, tipografia nítida e verde discreto. Não representa a função de pausar um envio.
