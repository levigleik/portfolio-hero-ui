# OSC Manager — conceito visual

Imagem gerada em 2026-10-26 a partir da captura anterior e da leitura do projeto OSC Manager. É uma proposta de interface para o portfólio, não uma captura da aplicação publicada. Os indicadores, nomes de projetos e resultados são fictícios.

O visual preserva o contexto real de projetos, OSCs, alunos, cursos, questionários e análise de respostas. Reorganiza o dashboard com filtros, indicadores compactos, barras por pergunta, gráfico de distribuição e uma tabela discreta, em uma linguagem visual clara com azul, teal e tons neutros.
